# 短剧内容改写成即梦视频生成需求的工作流程与标准

版本：2026-06-30  
用途：把任意输入内容，转化为适合提交给即梦生成视频的短剧分镜需求。

---

## 1. 文档定位

这套流程不是普通剧本写作标准，也不是传统拍摄分镜标准，而是一套面向 AI 视频生成的短剧需求转译标准。

它要解决的问题是：

1. 输入可能不是完整剧本，可能只是故事、商品卖点、爆款案例、人物关系、剧情大纲、口播稿、客户需求或一段模糊想法。
2. 在提交给即梦之前，必须先把输入处理成符合短剧规律的剧情。
3. 剧情成立之后，再用导演视角拆成镜头。
4. 镜头成立之后，最后才转成即梦能执行的视频生成需求。

核心链路是：

```text
任意输入
-> 短剧化编剧处理
-> 导演分镜拆解
-> 即梦生成需求
```

不要一上来就写提示词。  
提示词只是最后的交付格式，前面的剧情结构和镜头判断才决定生成效果。

---

## 2. 总原则

### 2.1 先让故事像短剧，再让镜头像分镜，最后才让文字像提示词

短剧生成失败，很多时候不是提示词格式的问题，而是前面的故事没有短剧化：

- 没有明确主角。
- 没有明确冲突。
- 没有情绪推进。
- 没有爽点、误会、反转或期待。
- 商品或转化点只是硬塞进去。
- 每段剧情没有明确动作。

所以第一步不是拆镜头，而是先把输入改成短剧。

### 2.2 每个生成单元优先控制在 8-12 秒

即梦生成不适合把每个 1 秒、2 秒镜头都单独生成。太短容易导致声音、配乐、人物状态和情绪连续性波动。

推荐做法：

- 按剧情发展合并镜头。
- 每个生成单元控制在 8-12 秒。
- 一个生成单元内可以包含多个子镜头。
- 子镜头之间默认硬切。
- 后期再按真实节奏裁剪。

不要为了凑平台时长，把一个完整的长镜头强行切碎。  
也不要把毫无剧情关系的短镜头硬合并。

### 2.3 画面、动作、表情、声音必须写在同一个时间段里

不要把画面、台词、音轨分成三个远离的段落。AI 视频生成时，最容易出错的就是“画面切到谁，声音就变成谁”。

正确写法是在每个时间段里同时写清楚：

- 当前参考图。
- 当前画面。
- 当前动作。
- 当前五官/身体变化。
- 当前说话人。
- 当前声音归属。
- 当前谁不张口。
- 配乐是否延续。

### 2.4 不生成字幕，但保留声音

当前标准是：

- 需要生成人物对白。
- 需要生成画外声、旁白或来信内容音频。
- 需要低音量连续配乐。
- 不允许出现任何字幕、水印、平台标识或 logo。

不要写成“不要出现任何文字叠加”。这个约束过宽，容易影响正常画面理解。  
只需要明确禁止字幕和平台类标识。

### 2.5 所有动作描述必须基于可见事实

提示词里不要写心理判断，也不要写抽象关系。

不要写：

```text
她很委屈。
他压迫感很强。
两人关系暧昧。
身体越过办公距离。
她感到被羞辱。
```

改成可执行的可见事实：

```text
她眼睛向下看，嘴角收住，双手握在腹前，肩膀略微内收。
他上半身向桌面方向前倾，右手放在文件夹旁，视线停在对方脸部。
两人之间隔着会议桌边缘，没有身体接触。
```

## 3. 标准工作流

## 阶段一：理解输入

### 目标

从任意输入中提取可以短剧化的故事素材。

### 输入可能包括

- 一个完整故事。
- 一个短剧剧本。
- 一个商品卖点。
- 一个带货需求。
- 一个爆款视频案例。
- 一段人物关系设定。
- 一段口播稿。
- 一组客户想表达的场景。
- 一段没有结构的想法。

### 需要提取的信息

1. **人物**
   - 谁是主角？
   - 谁是对手或阻碍？
   - 谁推动剧情变化？
   - 谁负责说服、刺激、误导或反转？

2. **目标**
   - 主角想要什么？
   - 商品、服务或关键道具在这个目标里起什么作用？

3. **冲突**
   - 当前局面哪里不顺？
   - 谁和谁的利益、态度、认知不同？
   - 观众为什么愿意继续看？

4. **情绪**
   - 开始是什么状态？
   - 中间如何升级？
   - 结尾如何释放？

5. **转化点**
   - 如果是带货短剧，产品在哪里自然出现？
   - 产品是解决问题、制造误会、体现身份，还是推动反转？

### 阶段产出

```text
故事核心：
主角：
对手/阻碍：
核心冲突：
情绪路径：
转化点：
短剧钩子：
结尾释放：
```

---

## 阶段二：短剧化编剧处理

### 目标

把原始内容改成符合短剧结构、节奏和观看习惯的剧情。

### 短剧结构标准

一条短剧至少要有以下结构：

1. **开场钩子**
   - 直接进入矛盾现场。
   - 不铺垫背景。
   - 让观众立刻知道“这里有事”。

2. **人物关系**
   - 用动作和对话说明关系。
   - 不靠旁白解释一大段设定。

3. **冲突升级**
   - 一方提出要求、质疑、隐瞒、炫耀、误解或试探。
   - 另一方产生反应。

4. **情绪变化**
   - 通过眼神、停顿、嘴角、手部、转身、沉默表现。
   - 不直接写心理台词。

5. **爽点或反转**
   - 身份反转。
   - 信息反转。
   - 态度反转。
   - 商品价值反转。
   - 误会解除或加深。

6. **下一段钩子**
   - 让观众想看后续。
   - 不要把所有情绪在一段里说完。

### 带货短剧的特殊要求

产品不能像广告一样突然出现。它应该承担剧情功能：

- 作为身份差异的证据。
- 作为关系变化的礼物。
- 作为解决问题的工具。
- 作为误会的来源。
- 作为反转的触发物。
- 作为主角被看见、被重视或被证明的媒介。

不要写：

```text
主角拿出产品，说这个产品非常好用。
```

更好的写法：

```text
主角本来因为穿着普通被质疑不适合出席晚宴，后来打开礼盒，发现对方提前准备了适合晚宴的衣服。产品成为关系反转和情绪释放的载体。
```

### 每 8-12 秒必须有一个剧情动作

每个生成单元不只是时间段，而是一个明确的剧情动作。

常见剧情动作包括：

- 试探。
- 撞见。
- 介绍。
- 质疑。
- 解释。
- 回避。
- 离开。
- 独处反应。
- 发现礼物。
- 阅读信息。
- 换装准备。
- 进入新场景。
- 爽点揭示。

### 阶段产出

```text
短剧化剧情梗概：

第1段：开场钩子，谁在什么场景做什么，冲突是什么。
第2段：关系说明，谁对谁说了什么，谁的反应是什么。
第3段：冲突升级，谁提出新信息，谁被影响。
第4段：情绪转折，主角独处或沉默反应。
第5段：反转/释放，关键道具或信息如何改变局面。
```

## 阶段三：导演视角切分镜头

### 目标

把短剧剧情拆成可被视频模型生成的镜头。

导演分镜不是写文学描述，而是写“画面上能拍到什么”。

### 每个镜头需要判断

1. **景别**
   - 全景：交代人物位置和关系。
   - 中景：人物互动、动作、站位。
   - 中近景：对话和反应。
   - 近景：表情变化。
   - 特写：手部、道具、信纸、商品、眼神。

2. **机位**
   - 正面。
   - 侧面。
   - 过肩。
   - 反打。
   - 俯拍。
   - 手部特写。

3. **运镜**
   - 固定。
   - 轻微推近。
   - 轻微跟随。
   - 反打硬切。
   - 稳定呼吸感。

4. **人物位置**
   - 谁在画面左侧？
   - 谁在画面右侧？
   - 谁坐着？
   - 谁站着？
   - 谁离门近？
   - 谁靠近桌边？

5. **动作**
   - 看向谁。
   - 转头。
   - 抬眼。
   - 低头。
   - 拿起道具。
   - 抱住文件夹。
   - 手指交握。
   - 伸手打开礼盒。

6. **五官变化**
   - 眼睛看向哪里。
   - 眉头是否略收。
   - 嘴角是否收住或上扬。
   - 嘴部是否开合。
   - 下巴是否略收。
   - 头部是否轻点或转向。

7. **身体细节**
   - 肩膀是否内收。
   - 双手是否握紧。
   - 身体是否前倾。
   - 是否站定。
   - 是否向门口移动。

8. **声音归属**
   - 当前画面里谁说话？
   - 如果画面切到反应镜头，声音是否仍来自上一人物？
   - 如果是手部、信纸、衣物或商品特写，声音是否为画外声？
   - 当前画面人物是否不张口？

### 分镜切分原则

1. 剧情动作变化时切镜头。
2. 说话对象变化时可以切反打。
3. 情绪反应需要被看见时切近景。
4. 商品、礼盒、信件、手部动作重要时切特写。
5. 空镜、转场、闪白不要作为独立生成单元，除非它承担剧情信息。
6. 同一场景内的短镜头优先合并到一个 8-12 秒生成单元。

### 阶段产出

```text
镜头编号：
剧情功能：
时长建议：
景别：
机位：
画面元素：
人物位置：
动作：
五官变化：
身体细节：
道具：
声音归属：
是否需要参考图：
```

## 阶段四：合并成即梦生成单元

### 目标

把导演分镜转成适合即梦生成的视频需求。

### 合并标准

一个即梦生成单元可以包含多个子镜头，但必须满足：

1. 属于同一段剧情动作。
2. 场景或情绪连续。
3. 人物关系没有突然跳变。
4. 声音主体能被明确锁定。
5. 参考图能覆盖每个关键画面。
6. 总时长建议在 8-12 秒。

### 不适合合并的情况

- 一个单元里跨越完全不同场景。
- 前后人物身份、服装、时间状态变化过大。
- 前一段是对话，后一段是独立商品展示，剧情关系不连续。
- 一个子镜头需要多人对话，另一个子镜头只有静物，但声音归属无法写清。
- 参考图无法支撑提示词里的主体动作。

### 参考图规则

每个生成单元要列出需要上传的参考图。

参考图不是越多越好。参考图的作用是锁定：

- 人物身份。
- 服装。
- 站位。
- 场景。
- 道具。
- 商品。
- 手部动作。
- 表情基准。

人物参考图必须能看清人物。  
静物参考图只能支撑静物、道具或商品，不要拿静物图去要求人物说话。  
身体局部参考图只能支撑身体、服装、手部和道具，不要拿它去要求脸部表演或口型。

### 如果输入本身没有参考图

如果输入只是故事、剧本、商品卖点或客户需求，没有现成参考图，则不要跳过参考图步骤。

先产出一份参考图需求清单：

```text
参考图1：主角A半身正面图，服装、发型、年龄感、表情基准。
参考图2：主角B半身正面图，服装、发型、年龄感、表情基准。
参考图3：核心场景图，例如办公室、卧室、酒店大堂、餐厅。
参考图4：关键商品或道具图，例如礼盒、衣服、文件夹、产品包装。
参考图5：关键动作参考图，例如人物手拿礼盒、打开信封、试穿衣服。
```

参考图需求要服务于分镜，不要为了好看而生成无用参考图。  
如果是带货短剧，用户自有产品图优先级最高，必须作为商品或道具参考图，不要让模型自行发明产品外观。

### 人物绑定规则

每个生成单元都要把人物身份写清楚，不能只写“他”“她”“老板娘”“秘书”。

绑定格式：

```text
参考图1：人物A=画面左侧站立，穿深色西装，手拿蓝色文件夹。
参考图2：人物B=画面右侧坐在桌边，穿浅色上衣，双手放在桌面。
```

如果涉及看向、指向、回应、介绍、递给、走向，必须同时写：

- 人物标签。
- 画面位置。
- 服装颜色。
- 手持道具。

不要让模型靠猜。

### 声音绑定规则

声音归属必须写进每个时间段。

可见人物说话：

```text
声：人物A说出“……”，口型同步，配乐低。
```

反应镜头里延续上一人物声音：

```text
声：“……”由人物A画外声继续说出；当前图人物B不张口；配乐低。
```

手部、信纸、商品特写：

```text
声：来信内容作为画外声发声；画面内手部和道具不张口；配乐低。
```

无对白：

```text
声：无对白；人物不张口；低音量配乐连续。
```

## 4. 即梦提示词标准格式

以下格式是最终可以提交给即梦的需求结构。

```text
生成时长：N秒，竖屏短剧片段。

基于已上传的参考图1-3生成。保持各图人物站位、人物距离、服装颜色、道具数量和场景布局一致；不要新增未在参考图中出现的人物或道具；不要新增身体接触、拥抱、拉扯、亲吻、争吵动作；只执行下方时间段中写明的动作；需要生成对白音频和低音量连续配乐；同一人物声线保持一致；切到反应镜头、身体局部、手部或道具时，声音主体不要跟随画面主体错误切换；不允许出现任何字幕、水印、平台标识或logo。

人物绑定：
参考图1：人物A=动作/位置：画面左侧站立，身体朝向人物B；外观/服装：深色西装；道具/环境：手拿蓝色文件夹。
参考图2：人物B=动作/位置：画面右侧坐在桌边，双手放在桌面；外观/服装：浅色上衣；道具/环境：桌面有杯子。
参考图3：物件C=红色礼盒放在床面，旁边有白色衣物。
涉及看向、指向、回应、介绍、走向、递给时，必须按人物标签、画面位置、服装颜色和手持道具执行，不要互换人物身份和动作对象。

音频总规则：
需要生成对白音频、人声、画外声和低音量连续配乐；人声要清楚，配乐音量低于对白，不盖过人物说话；每个时间段的声音归属以“声”描述为准；同一人物声线保持一致；子镜头硬切时，正在说话的人声不能因为画面切到别人、身体局部、手部或道具而换成当前画面主体；说话内容只用于人声、口型、嘴部开合、停顿和节奏，不生成画面字幕；配乐连续稳定，不要随镜头切换突然变大、变小、变调或中断。

动作变化点：
0.0-2.8秒：参考图1，起始保持参考图构图。画面：中近景，固定机位。动：人物A看向人物B，右手停在文件夹旁，身体保持坐姿。表：人物A眼神停在人物B方向，眉头略收，嘴部开合说话。姿：肩膀稳定，下巴略收。镜：固定中近景，可轻微推近。声：人物A说出“这里写对应对白”；口型同步；配乐低。

2.9-5.4秒：参考图2，硬切到参考图2构图。画面：人物B近景，固定反打。动：人物B听人物A说话，视线从人物A方向移向桌面，双手仍放在桌边。表：眼睛下移，嘴角收住，眉头轻微收紧。姿：身体站定或坐定，不主动靠近。镜：固定近景。声：“这里写人物A继续说的话”由人物A画外声继续说出；人物B不张口；配乐低。

5.5-8.8秒：参考图3，硬切到礼盒特写。画面：红色礼盒和白色衣物特写，固定俯拍。动：双手打开礼盒，衣物从盒内露出。姿：手部动作小幅、清楚，不出现人物脸部。镜：固定特写。声：画外旁白说出“这里写旁白或信件内容”；画面内手部和道具不张口；配乐低。

镜头：保持参考图构图，子镜头之间使用硬切，不把不同参考图的人物、场景、服装或声音融合。
```

## 5. 字段写作标准

### 5.1 生成时长

写法：

```text
生成时长：9秒，竖屏短剧片段。
```

规则：

- 推荐 8-12 秒。
- 如果剧情段真实只有 6 秒，可以生成 8 秒后后期裁剪。
- 如果剧情段超过 12 秒，优先按剧情动作拆成两个单元。

### 5.2 参考图

写法：

```text
基于已上传的参考图1-4生成。
```

规则：

- 提示词里不要写本地路径。
- 参考图清单应在交付材料中单独列出。
- 提示词只引用“参考图1、参考图2”。

### 5.3 人物绑定

写法：

```text
参考图1：人物A=画面左侧站立，穿灰色T恤，双手握在腹前。
```

规则：

- 用通用人物标签，不在通用标准里写死某个具体角色名。
- 如果项目中已有角色名，可以在具体项目里替换为角色名。
- 必须配合位置、服装、道具一起写。

### 5.4 动作

写法：

```text
动：人物A抬头看向人物B，右手仍按在文件夹边缘。
```

规则：

- 只写能被画面生成出来的动作。
- 不写动机、心理、关系判断。
- 不新增参考图里没有的人物、道具和身体接触。

### 5.5 五官变化

写法：

```text
表：眼睛从对方脸部移向桌面，嘴角收住，眉头略收。
```

规则：

- 优先写眼睛、眉头、嘴角、嘴部开合、头部、下巴。
- 只写小幅变化。
- 不写夸张表演。

### 5.6 声音

写法：

```text
声：人物A说出“……”；口型同步；配乐低。
```

规则：

- 需要人物对白。
- 需要旁白或画外声时必须写明归属。
- 需要低音量连续配乐。
- 不生成字幕。
- 不让声音主体跟随画面主体错误切换。

### 5.7 禁止项

标准写法：

```text
不允许出现任何字幕、水印、平台标识或logo。
```

不要写：

```text
不要出现任何文字叠加。
不要出现任何文字。
全程静音。
不要生成任何音频。
```

## 6. 质量检查表

交付前逐条检查：

1. 输入是否已经被改写成短剧结构，而不是直接变成提示词？
2. 主角、阻碍、冲突、情绪变化、反转是否清楚？
3. 每个 8-12 秒单元是否有明确剧情动作？
4. 分镜是否包含景别、机位、人物位置、动作、表情、声音？
5. 每个生成单元是否列出了参考图？
6. 人物绑定是否包含人物标签、位置、服装和道具？
7. 多人同框时，是否明确不要互换人物身份和动作对象？
8. 每个时间段是否同时写了画面、动作、表情、声音？
9. 对白是否写成音频和口型，而不是字幕？
10. 反应镜头、身体局部、手部、道具镜头中，声音归属是否写清？
11. 是否明确需要低音量连续配乐？
12. 是否明确不允许出现字幕、水印、平台标识或 logo？
13. 是否避免了“委屈、压迫、暧昧、关系张力”等心理判断词？
14. 是否避免了参考图无法支撑的人物动作或口型？
15. 是否避免了本地路径、内部编号、操作者备注进入最终提示词？
16. 单条提示词是否尽量控制在 1200 字以内？

## 7. 常见错误与修正

### 错误一：直接把故事翻译成提示词

错误：

```text
生成一个女人被丈夫误会，后来发现丈夫很爱她的短剧。
```

问题：没有人物动作、镜头、声音、参考图和剧情推进。

修正：

先写短剧结构，再拆分镜，再写生成需求。

### 错误二：把心理写成提示词

错误：

```text
她很委屈地看着对方。
```

修正：

```text
她眼睛向下，嘴角收住，双手握在腹前，头部停顿后轻轻抬起。
```

### 错误三：画面切到谁，声音就让谁说

错误：

```text
镜头切到人物B身体局部，人物B说出人物A的台词。
```

修正：

```text
声：“……”由人物A画外声继续说出；当前图人物B不张口；配乐低。
```

### 错误四：用静物参考图支撑人物表演

错误：

```text
参考图是礼盒特写，但提示词要求人物微笑说话。
```

修正：

```text
礼盒特写只写手部、礼盒、衣物动作；人物对白改为画外声或旁白。
```

### 错误五：为了禁止字幕，写成禁止所有文字

错误：

```text
不要出现任何文字叠加。
```

修正：

```text
不允许出现任何字幕、水印、平台标识或logo。
```

### 错误六：没有配乐

错误：

```text
只写人物对白，不写配乐。
```

修正：

```text
需要生成对白音频和低音量连续配乐；配乐低于对白，不盖过人物说话。
```

### 错误七：4 秒碎片化生成导致声音波动

错误：

```text
每个短镜头都单独生成 4 秒。
```

修正：

```text
按剧情发展合并成 8-12 秒生成单元，子镜头之间硬切，后期再裁剪。
```

## 8. 最终交付物标准

一份合格的即梦短剧生成需求，至少包含：

1. **短剧化剧情梗概**
   - 说明主角、冲突、情绪路径和转化点。

2. **导演分镜表**
   - 每个镜头的剧情功能、景别、机位、人物位置、动作、表情、声音。

3. **即梦生成单元**
   - 每个单元 8-12 秒。
   - 每个单元列出参考图。
   - 每个单元给出可直接复制的提示词。

4. **参考图清单**
   - 每张参考图对应哪个人物、道具、场景或动作。

5. **检查说明**
   - 是否有字幕禁止。
   - 是否有配乐。
   - 是否有人物对白。
   - 是否有声音归属。
   - 是否有角色绑定。
   - 是否存在参考图不支撑提示词的问题。

## 9. 一句话标准

这套流程的本质是：

```text
先把输入改成有冲突、有节奏、有情绪推进的短剧；
再把短剧拆成导演能拍的镜头；
最后把每个镜头单元写成即梦能执行、不会混人、不会串音、不会生成字幕的需求。
```
